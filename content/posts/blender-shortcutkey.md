### 선택한 오브젝트 삭제 확인 - \[X\]

### \[G\] \[R\] \[S\] 키에 \[X\] \[Y\] \[Z\] 키를 연계하여 축 관련 작업 가능

예시

\[G\] 키 입력 후 \[X\] 키 입력 \> X축으로 오브젝트 이동 가능

\[G\] 키 입력 후 \[Y\] 키 입력 \> Y축으로 오브젝트 이동 가능

\[G\] 키 입력 후 \[Z\] 키 입력 \> Z축으로 오브젝트 이동 가능

다음과 같이 \[R\], \[S\]도 가능

### 오브젝트 편집 모드 \[Tab\]

![](/images/posts/blender-shortcutkey/22.webp)

![](/images/posts/blender-shortcutkey/23.webp)

Tab키 선택 시, 선택한 오브젝트의 Edit Mode로 진입됨

각각 숫자 키패드를 통해 편집할 영역을 고를 수 있음

\[1\] : 점(Vertex)

\[2\] : 선(Edge)

\[3\] : 면(Face)

![](/images/posts/blender-shortcutkey/24.webp)

### 오브젝트 편집 모드 \> 새로운 면 뽑기 \[E\]

Extrude

![](/images/posts/blender-shortcutkey/25.webp)

### 오브젝트 편집 모드 \> 면 나누기 \[Ctrl\] + \[R\]

노란 선을 가운데에 두고 싶다면 \[ESC\]

노란 선을 여러 개 만들고 싶다면 마우스 휠 올리기

노란 선을 줄이려면(최소 1개) 마우스 휠 내리기

![](/images/posts/blender-shortcutkey/26.webp)

### 루프 선택(한 줄 선택) \[Shift\] + \[Alt\]

가로 선에 커서를 가져다 대고 선택하면 가로선 묶음 선택됨

세로 선에 커서를 가져다 대고 선택하면 세로선 묶음 선택됨

![](/images/posts/blender-shortcutkey/27.webp)
