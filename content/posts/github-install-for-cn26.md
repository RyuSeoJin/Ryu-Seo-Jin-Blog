## 5. 깃허브 데스크탑 사용법

깃허브 데스크탑을 통해 포트폴리오 폴더를 이용하려면 다음과 같은 5가지 동작을 알고 있어야 합니다.

- Fetch - 해당 깃에 적용된 변경 사항을 확인(최신화)한다

- Pull - 다른 사람이 작업한 내용을 가져온다

- Commit - 내가 작업한 내용을 반영한다

- Push - 본인이 작업한 내용을 넣는다

- Discard - 본인이 작업한 내용을 취소시킨다

현재는 이렇게 5가지만 알아도 됩니다.

![](/images/posts/github-install-for-cn26/12.webp)

### 5.1. 깃허브 데스크탑을 키면 항상 이용 중인 파일의 버전을 최신화\[Fetch\]해야 합니다.

#### 1. 작업을 하실 때에는 우측 상단의 \[Fetch origin\] 버튼을 선택하여 가장 최신화된 버전을 확인하고, 가장 최신화된 버전을 유지해야 합니다.

![](/images/posts/github-install-for-cn26/13.webp)

- Fetch origin인 경우 \> 최신화된 버전입니다. 그대로 작업을 진행하면 됩니다.

- Pull origin인 경우 \> 누군가 수정하여 버전이 최신화되지 않았으므로, \[Pull origin\] 버튼을 선택하여 최신 버전으로 업데이트를 해야 합니다.
  ![](/images/posts/github-install-for-cn26/14.png)

 

![](/images/posts/github-install-for-cn26/15.webp)

### 5.2. \[Commit\]을 통해 본인이 작업한 작업물을 올릴 수 있습니다.

#### 1. 본인이 작업한 내용이 있으면, 깃허브 데스크탑에 변경사항이 생기는 것을 알 수 있습니다.

![](/images/posts/github-install-for-cn26/16.webp)

---

#### 2. 업데이트에 관련된 제목 및 설명을 작성한 후, \[Commit {0} file to main\] 버튼을 선택하면 \[Fetch origin\] 버튼이 \[Push origin\] 버튼으로 변경됩니다.

**★★★★★\[Commit\] 버튼을 선택하기 전, 가장 최신화된 버전으로 업데이트해주세요! 안 하면 서로 작업물이 엉킬 수 있습니다★★★★★**

![](/images/posts/github-install-for-cn26/17.webp)

---

#### 3. 만약 작업을 반영하기 싫다면, 좌측 하단의 \[Undo\] 버튼을 선택하여 Commit을 정지시킬 수 있습니다.

![](/images/posts/github-install-for-cn26/18.webp)

---

#### 4. 작업을 파일에 반영시키고 싶다면 \[Push origin\] 버튼 선택하여, 본인이 작업한 내용을 반영할 수 있습니다.

![](/images/posts/github-install-for-cn26/19.webp)

### 5.3. \[Discard\]를 통해 작업한 내용을 취소할 수 있습니다.

본인이 작업한 내용을 삭제하고 싶다면, 변경사항을 \[마우스 우클릭\] 동작 \> \[Discard changes…\] 버튼을 선택하여 작업한 내용을 취소시킬 수 있습니다.

**★★★★★취소하는 경우에는 해당 작업물을 ‘해당 버전에 적용되고 있었던 작업물 상태’으로 되돌립니다. 이 부분 꼭 명심하세요.★★★★★**

- 해당 버전에서 A 작업물은 2026.03.15 오후 7시에 마지막으로 수정되었었음
  - 이후 A 작업물을 변경 (2026.03.16 오후 3시)

  - 이 상태에서 Discard를 한다면 ‘2026.03.15 오후 7시’ 기준으로 작업물이 되돌아감.

Discard의 경우에는, 남의 작업물이 저로 인해 변경점이 있을 때 사용하시면 됩니다.

ex) 나는 내 작업물만 변경했는데 어느 순간 다른 작업자의 파일에도 변경 사항이 있네? → 해당 파일은 업로드하면 안되는 부분입니다. Discard를 통해 제거 후 **본인 작업물만** ‘commit(반영)’ 해주세요!

![](/images/posts/github-install-for-cn26/22.webp)

![](/images/posts/github-install-for-cn26/23.webp)

## 6. 연동되었다면, 다음과 같이 본인 작업 폴더를 만들어 봅시다.

연동이 완료되었다면 다음과 같이 따라해보세요.

- {작업자이름} 폴더 **복사** 후, 본인 이름으로 변경

- **{작업자이름} 기존 폴더는 삭제하지 않고 그대로 냅둬주세요!**
  ![](/images/posts/github-install-for-cn26/24.webp)

- 깃허브 데스크탑에서 우측 상단의 Fetch origin을 선택하여 최신 버전인지 먼저 확인하기

- 최신 버전이 확인되면, 자신이 추가한 변경사항을 Commit하기
  - Summary(제목)은 {작업자명}\_{작업한내용} / ex) 정준호\_폴더생성
  Description(설명)은 {작업내용} 입력 / ex) 폴더 생성 진행 완료

- \[Push origin\] 버튼 선택하여 작업물 반영하기

여기까지 정상적으로 완료되었다면 당신은 깃허브 마스터입니다(?) 축하드립니다.
